DP days
days with any DP

DP time is counted between DP ON and DP OFF entries: the DP light, or any entry containing “DP ON” / “on DP” and “DP OFF” / “off DP” / “out of DP”. With hours of the day chosen, only DP time inside those hours is counted, each day. However many hours the vessel is on DP in a day, it counts as one DP day. This is the vessel's time on DP – in a personal DP logbook only your own time on DP watch counts.

Print / save as PDF

To save a PDF, choose “Save as PDF” as the printer (on iPad / iPhone: Share in the print preview).

Import backup

Merge adds the entries from the file that are not here yet and keeps everything already on this device. Replace deletes what is on this device and loads the file instead.

Settings

The logo appears at the top of the logbook and on printouts, and is saved in the backup file. It is not uploaded anywhere. Use a PNG or SVG with a transparent or white background.

These appear in the drop-down when you fill in an event. End a line with … to leave it open for typing more, e.g. “Heading changed to …”. Events you typed by hand before are also offered automatically.

Data

Every change is saved automatically as you type, in this browser on this device only. To use the logbook on another device, save a backup file here and import it there – you can merge it with what is already on that device or replace it. Save a backup file regularly.

Help: logo, app icon, moving data

Logo inside the logbook

Settings → Logo → “Choose image…” (PNG or SVG) or “Generic ship icon”. It shows at the top and on printouts and is saved in the backup file. This is separate from the app icon on your home screen.

App icon on the home screen

The icon is taken from the app when you add it to the home screen, so to change it, remove the icon and add the app again.

  • iPad / iPhone: in Safari tap Share → “Add to Home Screen”. For your own picture on this device only: open the Shortcuts app → + → “Open URL” (the app's address) → “Add to Home Screen”, then tap the small icon and choose your photo.
  • Android: in Chrome tap ⋮ → “Install app” or “Add to Home screen”. A custom icon is set in your launcher (long-press the icon → Edit), depending on the phone.
  • PC / Mac: in Chrome or Edge click the install icon in the address bar. For a desktop shortcut with your own icon on Windows: right-click the shortcut → Properties → Change Icon → choose an .ico file.
  • For every device at once: replace the file dp-logbook/icon.png in the GitHub repository with a square 512 × 512 PNG, then add the app to the home screen again.

Moving the logbook to another device

Save a backup file here, open the app on the other device and use “Import backup file” (Merge keeps what is already there). Data lives only in the browser it was entered in. On iPad the home-screen icon can keep its own separate data from Safari, so import the backup in the place where you will actually use the app.
